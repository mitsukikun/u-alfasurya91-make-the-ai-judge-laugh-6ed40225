One-line office joke for a comedy club headliner judge: under 200 characters,
a true office observation with a surprising turn, kept tight and original.

## The joke

> The meeting ended ten minutes early, so we all just sat there in silence, afraid to be the first to enjoy it.

## How to run

```bash
python3 main.py
```

This writes the joke to `/output/entry.txt` (UTF-8, 1–200 characters).

## Why it works

- **True observation:** meetings ending early are rare, and nobody quite trusts the gift.
- **Surprising turn:** instead of celebrating, everyone freezes — enjoying it feels like breaking a rule.
- **Tight:** one sentence, no setup wasted, the punch lands on the last words.
